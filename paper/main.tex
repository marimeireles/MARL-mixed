\begin{abstract}
We study how \emph{observational heterogeneity}---differences in what agents perceive about a shared interaction---shapes cooperation in multi-agent reinforcement learning. Using collective reinforcement-learning dynamics (CRLD), we model two memory-two agents in an Iterated Prisoner's Dilemma where one observes the full history and the other is selectively blind along controlled dimensions. Across more than a thousand initializations per scenario, cooperation is \emph{fragile}: the deterministic dynamics mostly converge to mutual defection, and every restriction of the partial observer reduces cooperation. The collapse is sharpest---essentially total---when an agent cannot perceive its \emph{own} past actions, the substrate reciprocity requires. The two agents nonetheless earn nearly identical reward (the better-informed agent gains no systematic advantage; exploitation is rare), so the dominant failure mode of heterogeneity is shared defection, not domination. Reading the dynamics as a flow in policy space makes these basins explicit, and a memory sweep shows the cooperative basin is itself created by memory---absent at memory one, it emerges and enlarges with history, a deterministic echo of the intrinsic-fluctuation route to cooperation. These corrected results temper earlier optimistic claims and isolate self-referential observability as a mechanism learning agents need to sustain reciprocity.
\end{abstract}

\section{Introduction}

Cooperation underlies much of human flourishing \cite{1, 2}, yet the complexity of modern societies routinely produces social dilemmas in which individual incentives and collective welfare diverge---from climate policy \cite{5} and pandemic response \cite{6} to political stalemate \cite{12, 7} and economic distrust \cite{3}. Such problems are increasingly modeled with Markov Decision Processes and reinforcement learning (RL), which capture how agents---governments, firms, consumers---adapt strategies from partial observations of an evolving environment \cite{6, 4}.

A defining feature of real-world actors is that they do \emph{not} perceive their shared environment identically: a firm and a regulator see different slices of the same market, and treaty negotiators hold asymmetric information about each other---and about their own commitments. We therefore ask a focused question: \emph{how does heterogeneity in observability shape whether learning agents come to cooperate?} We isolate observability from other heterogeneities (learning rate, risk tolerance) so its effect can be measured cleanly, in the general-sum Iterated Prisoner's Dilemma \cite{9}.

This paper revisits and corrects an earlier work-in-progress study by the present authors, whose preliminary report suggested that cooperation between knowledge-asymmetric agents emerges readily. A careful, parameter-controlled reproduction shows a more nuanced picture: cooperation is achievable but \emph{fragile}, most observational impairments suppress it, and the loss of \emph{self}-observability is uniquely destructive. We present the corrected methodology, equations, and regenerated results.

\section{Methods}

\subsection{Learning dynamics}

We simulate two agents, \(i \in \{1,2\}\), each choosing an action \(a^i \in \{c,d\}\). Rather than noisy, sample-based simulations, we use \emph{collective reinforcement learning dynamics} (CRLD) \cite{10, 9, 14}, the deterministic, infinite-batch (strategy-averaged) limit of temporal-difference learning: it replaces stochastic value updates with deterministic equations in \emph{strategy space} that are efficient and analytically transparent. Each agent holds a policy \(x^i(a\mid o)\) over actions given an \emph{observation} \(o\), which need not coincide with the true state \(s\)---the lever for perceptual heterogeneity (Section~\ref{sec:obs}). The policy updates along the strategy-averaged temporal-difference error \(\delta^i\) via the policy-space replicator--mutator map \cite{9, 14} (not a tabular value update):

\begin{equation}
x^i_{t+1}(a\mid o) \;=\;
\frac{x^i_{t}(a\mid o)\,\exp\!\big(\alpha_i\,\beta_i\,\delta^i_t(o,a)\big)}
{\sum_{b} x^i_{t}(b\mid o)\,\exp\!\big(\alpha_i\,\beta_i\,\delta^i_t(o,b)\big)},
\label{eq:update}
\end{equation}

where \(\alpha_i \in (0,1]\) is the learning rate and \(\beta_i>0\) is the choice intensity (inverse temperature) controlling the exploration--exploitation trade-off. Equation~\eqref{eq:update} replaces the explicit \(\epsilon\)-greedy action selection and tabular SARSA value update of standard RL; in the deterministic limit, softmax action selection with intensity \(\beta_i\) is folded directly into the policy and its update.

The strategy-averaged temporal-difference error for actor--critic learning is

\begin{equation}
\delta^i_t(o,a) \;=\; (1-\gamma_i)\,\bar{R}^i(o,a)\;+\;\gamma_i\,\overline{V}^i_{\text{next}}(o,a)\;-\;\overline{V}^i(o),
\label{eq:tderror}
\end{equation}

where \(\gamma_i \in [0,1)\) is the discount factor, \(\bar{R}^i(o,a)\) the strategy-averaged immediate reward, \(\overline{V}^i(o)\) the value of observation \(o\) under the joint policy, and \(\overline{V}^i_{\text{next}}(o,a)\) the strategy-averaged successor value; the \((1-\gamma_i)\) prefactor puts immediate and future returns on the same scale \cite{14}. Using the expected successor value makes this the deterministic, on-policy form of TD learning (the infinite-batch limit of Expected SARSA \cite{13}); the values \(\overline{V}^i\) solve the corresponding Bellman system in closed form. Under partial observability all averages additionally integrate the belief over true states induced by the observation model, following the partially observable CRLD formulation \cite{15}.

\paragraph{The dynamics as a flow.}
Equations~\eqref{eq:update}--\eqref{eq:tderror} define a deterministic map on the joint policy---equivalently, a vector field (a \emph{flow}) on strategy space. From any joint policy the learning rule points in a definite direction, the fixed points where the flow vanishes are the learned equilibria, and the \emph{cooperation rate} we report is precisely the measure of the basin of attraction of the cooperative fixed point under random initial policies. Visualizing this flow (Figures~\ref{fig:flowgrid}--\ref{fig:memory}) exposes \emph{why} a scenario does or does not cooperate, complementing the reward statistics with the geometry behind them.

Because \(\alpha_i,\beta_i,\) and \(\gamma_i\) can be set per agent, this framework natively supports \emph{heterogeneous} agents that differ in learning speed and effective risk tolerance. In this paper we hold these parameters equal across agents (Appendix) so that the sole heterogeneity under study is observability.

\subsection{Environment}

The environment is the Iterated Prisoner's Dilemma (IPD). The one-shot payoffs (Table~\ref{tab:payoff}) are $R=1$ (mutual cooperation), temptation $T=1.2$, sucker $S=-0.5$, and punishment $P=0$, satisfying $T>R>P>S$ and $2R>T+S$. We embed the stage game into a \emph{memory-two} history (an agent's state is the previous two rounds' outcomes)---the smallest history rich enough to host the reciprocal strategies (win-stay--lose-shift, tit-for-tat) that direct reciprocity relies on \cite{11, 16}, yet low-dimensional enough for exhaustive analysis.

\subsection{Observational heterogeneity}
\label{sec:obs}

Agent~1 is a \emph{full observer} (perceives both agents' last two actions without aliasing). Agent~2 is a \emph{partial observer}: along controlled dimensions, parts of the most recent round are masked, aliasing several true states to one observation (its belief is spread uniformly over them) while the prior round stays fully observed. We study four restrictions of Agent~2; exact state-to-observation maps are in the Appendix (Tables~\ref{tab:exp-selfaware}--\ref{tab:exp-def}).

\begin{itemize}
  \item \textbf{Self-aware}: Agent~2 remembers its \emph{own} most recent action but not Agent~1's (it cannot see what the other did last round).
  \item \textbf{Non-self-aware}: Agent~2 remembers Agent~1's most recent action but not its \emph{own} (it cannot see what it itself did last round).
  \item \textbf{Cooperation-tracking}: Agent~2 perceives Agent~1's last action only when Agent~1 \emph{cooperated}; Agent~1's defections are masked.
  \item \textbf{Defection-tracking}: Agent~2 perceives Agent~1's last action only when Agent~1 \emph{defected}; Agent~1's cooperations are masked.
\end{itemize}

For each scenario we run the deterministic dynamics from $N=1{,}200$ random softmax initial policies until a fixed point is reached (tolerance $10^{-5}$, at most $4{,}000$ steps), discard the small fraction of non-converged runs, and record each agent's converged average reward $\bar R^i$. We summarize outcomes by the rate of \emph{mutual cooperation} (both agents' average reward $>0.9$, i.e.\ close to $R=1$) and by mean reward per agent.

\section{Results}

We read the same dynamics in two complementary ways: as the flow geometry in policy space (Figure~\ref{fig:flowgrid}), and as reward statistics over $N=1{,}200$ random initializations per scenario (Figure~\ref{fig:summary}).

  \caption{Learning flow of the heterogeneous memory-two IPD (actor--critic CRLD), one panel per observability condition of the partial observer (Agent~2; Agent~1 is always a full observer). Arrows are the deterministic learning update at each joint policy; purple curves are two trajectories; axes are each agent's cooperation probability. Mutual cooperation is the corner $(1,1)$, defection $(0,0)$. A basin draining to cooperation exists under full observability, cooperation-tracking, and---weakly---self-awareness, but the flow collapses toward defection when the partial observer cannot see its \emph{own} last action (non-self-aware) or is blind.}
  \label{fig:flowgrid}

\paragraph{Cooperation is fragile, and impairing observability suppresses it.}
Under full observability the dynamics reach mutual cooperation in only about $14\%$ of random initializations; the rest collapse to defection. The flow makes this concrete: even the full-observability panel of Figure~\ref{fig:flowgrid} has most arrows pointing into the defection corner, with only a small basin draining to $(1,1)$---so even with perfect, symmetric information, defection is the modal attractor at these parameters. Every observational restriction of Agent~2 shrinks the cooperative basin further (Figures~\ref{fig:flowgrid},~\ref{fig:summary}a), making observational completeness a prerequisite---not a guarantee---for cooperation.

\paragraph{Losing self-observability is catastrophic.}
The starkest contrast concerns \emph{whose} action is hidden. When Agent~2 cannot observe its \emph{own} last action (non-self-aware), the flow drains uniformly to defection (Figure~\ref{fig:flowgrid}, top-right) and essentially every run converges to mutual defection, with both agents earning a reward indistinguishable from the punishment payoff $P=0$. Retaining self-observability while losing sight of the \emph{other} agent (self-aware) is also damaging but strictly less so: a nonzero fraction of trajectories still climb toward cooperation (Figure~\ref{fig:flowgrid}, top-middle). Mechanistically, an agent that cannot identify its own move cannot implement a reciprocal, history-dependent rule at all---it cannot ``stay'' or ``shift'' relative to its own behavior---so the substrate for direct reciprocity disappears. This recovers and sharpens the earlier observation that the absence of self-awareness is uniquely destructive, while clarifying that self-awareness is necessary but far from sufficient.

\paragraph{What an agent chooses to track matters, but exploitation is rare.}
Conditioning \emph{which} of the other's moves are visible also shapes outcomes. An agent that perceives the opponent's cooperations (cooperation-tracking) sustains more cooperation than one that perceives only its defections (defection-tracking); see the corresponding panels of Figure~\ref{fig:flowgrid} and Figure~\ref{fig:summary}a. Visibility of the partner's cooperation provides the positive signal on which reciprocity can build, whereas a perception filtered toward the partner's defections biases the learner toward distrust. Importantly, we do \emph{not} observe systematic exploitation in either case: the joint-reward distributions are close to symmetric, and one-sided outcomes (one agent at the temptation payoff, the other at the sucker payoff) are uncommon. The earlier framing of these scenarios as ``Agent~2 being exploited'' versus ``exploiting'' is not supported; the dominant effect of perceptual filtering is on the \emph{shared} cooperation rate, not the division of spoils.

\paragraph{Memory creates and enlarges the cooperative basin.}
The cooperative basin is not a fixed feature of the game but a product of \emph{memory}. Re-running the full-observability dynamics at memory one, two, and four (Figure~\ref{fig:memory}) shows that at memory one the learning flow does not reach mutual cooperation from our initializations; a cooperative fixed point at $(1,1)$ becomes reachable only at memory two, and its basin enlarges at memory four. Longer histories let agents represent richer reciprocal strategies (memory-$k$ tit-for-tat / win-stay--lose-shift) that turn cooperation into a deterministic attractor. This is the deterministic counterpart of the finite-batch \emph{intrinsic fluctuations} that promote cooperation in the memory-one IPD \cite{8} (Appendix, Figure~\ref{fig:memory}): memory and sampling noise enlarge the cooperative basin by different routes. It also justifies memory two as the smallest setting in which heterogeneous reciprocity can be studied at all.

\paragraph{Heterogeneity costs both agents, and favors neither.}
The two agents earn almost identical average reward in every scenario (Figure~\ref{fig:summary}b): the gap is below $0.015$ in reward units everywhere, it is not consistently in favor of the better-informed agent, and in the cooperation-tracking scenario the \emph{partial} observer is in fact marginally ahead. The better-informed agent enjoys no systematic advantage from its superior perception. This contradicts our earlier report that more knowledgeable agents reliably earn more; we trace that claim to a parameter bug (Appendix), and find that with a valid discount factor the apparent advantage disappears or reverses. The headline of heterogeneity is therefore mutual loss---both agents forgo the cooperative surplus---rather than a winner taking the other's share. The aggregate cooperation rates and per-agent rewards across all scenarios are summarized in the Appendix (Figure~\ref{fig:summary}); a representative trajectory (Figure~\ref{fig:trajectory}) corroborates this picture.

\section{Discussion}

The corrected results support a cautionary reading of heterogeneous-observability cooperation. In the deterministic learning limit, a heterogeneous Iterated Prisoner's Dilemma does not spontaneously favor cooperation; it favors defection, and perceptual asymmetries make matters worse rather than better. The clearest positive statement we can make is structural: an agent must be able to observe its own past behavior to participate in reciprocity at all, and shared visibility of cooperative moves is what allows the residual cooperation to persist. Where our earlier preliminary report read these simulations optimistically, the controlled reproduction reads them as a map of \emph{failure modes}---which perceptual deficits are survivable and which are fatal.

We note that other lines of work recover robust cooperation in closely related settings by departing from the strict deterministic limit---most relevantly, intrinsic fluctuations from finite-batch sampling can stabilize cooperation that the infinite-batch dynamics miss \cite{8}. Our memory result (Figure~\ref{fig:memory}) is a complementary, purely deterministic route to the same place: enlarging the agents' history enlarges the cooperative basin without invoking noise at all. That both extra memory and finite-batch fluctuations expand the same basin suggests cooperation here is gated by how much reciprocal structure the learners can represent and stabilize; reconciling these mechanisms under the observability deficits studied here---in particular whether fluctuations can rescue the non-self-aware case that memory alone cannot---is a natural next step.

\section{Future work and limitations}

Natural next steps are to (i) sweep $\beta$ and $\gamma$ to map where, if anywhere, observational heterogeneity becomes cooperation-promoting; (ii) reintroduce finite-batch fluctuations \cite{8} to test whether they rescue cooperation under partial observability where memory alone cannot; and (iii) extend beyond the IPD to public-goods, bargaining, and common-pool games, eventually connecting these low-dimensional dynamics to deep-RL and language-model agents. The present conclusions are correspondingly bounded: the IPD captures a narrow slice of strategic behavior; CRLD assumes deterministic, infinite-batch update rules rather than human idiosyncrasy; outcomes depend on the chosen parameters and on the single regime we report; and cooperation rates are statements about the measure of a basin of attraction under random initial policies, not about any single trajectory.

\section{Appendix / supplemental material}

\subsection{Software and reproducibility}

All experiments use an extension of the open-source \texttt{pyCRLD} library \cite{10} that adds heterogeneous per-agent observation tensors. The deterministic dynamics, observation-tensor construction, and figure-generation scripts used for every result and figure in this paper are released with the camera-ready version.

\paragraph{Corrections relative to the earlier preliminary report.}
The present version fixes four issues in the earlier exploratory code and writeup. (1) \emph{Invalid discount factor:} the mixed-observability scenario underlying the earlier ``more knowledgeable agents earn more'' claim had been run with a discount factor of $10$, outside the valid range $[0,1)$. This makes the $(1-\gamma)$ prefactor negative and the value-function solve ill-posed; in a controlled comparison it both inflates the apparent cooperation rate (here, from $\approx14\%$ to $\approx21\%$) and manufactures a spurious reward advantage for the full observer that vanishes---indeed reverses---at $\gamma=0.9$. All scenarios here use $\gamma=0.9$. (2) \emph{Stale-variable reuse:} several cells reported cooperation percentages from a variable computed for the \emph{previous} scenario, so some printed statistics did not correspond to the figure beside them; and some figure legends carried hard-coded percentages rather than values derived from the data. (3) \emph{Math:} the learning rule is now stated as the policy-space CRLD update of Eqs.~\eqref{eq:update}--\eqref{eq:tderror} actually implemented by the framework, rather than a tabular SARSA value update. (4) \emph{Consistent pipeline:} all cooperation and exploitation statistics are re-derived under one identical, controlled pipeline across all scenarios, which removes per-scenario drift and overturns the earlier exploitation narrative.

\subsection{Parameters}

For all experiments we use learning rate $\alpha=0.1$, discount factor $\gamma=0.9$, and choice intensity $\beta=1$, identical across both agents. Memory length is two ($h=(2,2,2)$ in the history-embedding convention). Each scenario uses $N=1{,}200$ random softmax initial policies; trajectories run up to $4{,}000$ steps with fixed-point tolerance $10^{-5}$.
